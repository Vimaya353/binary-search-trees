# Binary Search Trees

A balanced binary search tree built in JavaScript, as part of The Odin Project.

## Features

- Build a balanced tree from an array (sorted, no duplicates)
- `includes`, `insert`, and `deleteItem`
- Traversals: level-order, in-order, pre-order, post-order
- `height`, `depth`, `isBalanced`, and `rebalance`
- `prettyPrint` to see the tree in the console

## How to run

```bash
git clone https://github.com/YOUR-USERNAME/binary-search-trees.git
cd binary-search-trees
node driver.js
```

The driver script creates a tree, unbalances it, rebalances it, and prints the results.

## Files

- `tree.js`: the Node and Tree classes
- `driver.js`: a script that tests everything
